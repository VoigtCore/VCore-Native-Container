# VCore Native Container — Experimental Edition For Engines VCore

## Português

Primeira edição pública: VCore Engine Studio **0.1.0-experimental** (revisão r4)
e Engine Development Platform **0.2.0-experimental** para Windows x64.

- Abra o Studio, importe pacotes `.vc` e inspecione identidade, integridade e assinatura.
- Desenvolva com os contratos públicos, teste, construa e assine quando autorizado.
- Explore o exemplo `hello-vcore`, as capturas reais e o [manual ilustrado](manual.pt-BR.md).
- O diagrama explica a divisão entre engenheiro, operador e execução.

O ZIP inclui Node.js e as ferramentas públicas. Extraia tudo e abra o EXE.
Confira os arquivos usando SHA256SUMS. O EXE não tem assinatura Authenticode.

**Executar exige um Native Container fornecido separadamente pelo operador**, com
conexão, credenciais, política, confiança no publisher e admissão. O download não
contém o runtime privado, Core, banco, chaves privadas ou fontes do Pulse.
A assinatura do exemplo é demonstrativa; não é autorização oficial.

Studio é Windows. Instalação limpa, ciclo completo do serviço Windows, estabilidade
sob carga e aceitação desta entrega no Linux continuam pendentes. Edição experimental;
**produção NOT_READY**. Pulse comercial e Munich não foram alterados.

## English

First public edition: VCore Engine Studio **0.1.0-experimental** (r4 revision)
and Engine Development Platform **0.2.0-experimental** for Windows x64.

- Open Studio, import `.vc` packages and inspect identity, integrity and signatures.
- Develop against public contracts, test, build and sign when authorized.
- Explore `hello-vcore`, real screenshots and the [illustrated guide](manual.en.md).
- The workflow diagram explains engineer, operator and execution responsibilities.

The ZIP includes Node.js and public tooling. Extract everything and open the EXE.
Check files against SHA256SUMS. The EXE is not Authenticode signed.

**Execution requires a separately provisioned operator Native Container**, including
connection, credentials, policy, publisher trust and admission. This download excludes
the private runtime, Core, databases, private keys and commercial Pulse source.
The demo signature is an example, not official authorization.

Studio is Windows-only. Clean installation, the complete Windows service lifecycle,
load stability and Linux acceptance for this release remain unverified. Experimental;
**production NOT_READY**. Commercial Pulse and Munich were not changed.
