# Security / Segurança

Experimental evaluation only. Edição experimental para avaliação.

- Package import is not trust or admission. Importar não admite nem autoriza.
- Demo signature is not official publisher trust. Assinatura demonstrativa não é confiança oficial.
- No private Core, database or key is included. Nenhum Core privado, banco ou chave privada incluído.
- Developer tests run as your user. Testes locais executam como seu usuário.
- Host administrators remain trusted. Administradores do host continuam na fronteira de confiança.
- Runtime and operator provisioning are separate. Runtime e provisionamento do operador são separados.
- No claim of perfect memory secrecy or production readiness. Sem promessa de sigilo absoluto em memória ou prontidão de produção.

Do not publish credentials or sensitive logs in issues. For a suspected vulnerability,
contact **rafael@voigtcore.com.br** with a minimal description, without secrets.
Não publique credenciais ou registros sensíveis nas issues. Para suspeitas de falha,
use o contato acima com uma descrição mínima, sem segredos.
